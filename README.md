# Academic Graph Skill

科研绘图 Skill 归档仓库（赛道主目录）。每个题目一个顶层文件夹，题目下按版本号归档具体 Skill 版本及其平台得分记录。

## 目录结构

```
Academic-Graph-Skill/
├── 图形摘要/                    # 同一题目下保留多个版本
│   ├── README.md
│   └── v1.3.0/                  # Attempt 74019，83 / 100
│       ├── SKILL.md
│       ├── scripts/
│       ├── references/
│       ├── SCORE.md
│       └── PROVENANCE.json
└── 实验装置与技术路线图/          # 一个题目 = 一个顶层目录
    ├── README.md                  # 题目索引：版本表与命名约定
    └── v1.0/                      # 一个版本 = 一个子目录
        ├── SKILL.md               # Skill 入口（YAML frontmatter + 流程）
        ├── scripts/               # 执行脚本
        ├── assets/                # 配置、配色、字体链、图元库
        ├── docs/                  # 用法、IR schema、限制与失败清单
        ├── examples/              # 合成示例（标注为非正式案例结果）
        ├── CHANGELOG.md
        └── SCORE.md               # 该版本平台得分与评审原文
```

## 约定

1. 版本目录内容与提交到平台的 Skill 本体一致，不加修改；平台得分写入同目录 `SCORE.md`。
2. `examples/` 中的示例一律标注为合成示例，不冒充正式案例结果。
3. 得分、评级与评审原文照录平台返回，不做推断或美化。
