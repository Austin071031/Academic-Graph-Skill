## 二、评分细则与改进优先级

原题 100 分中，“实际效果”占 40 分，直接考察任务完成度、科学正确性、完整性和可核验性；“使用增益”占 25 分，要求相对基础 Agent 的实际质量提升；“创新增益”占 15 分，要求可证明的方法改进；可靠性与生态贡献分别占 10 分。GitHub 公开作品链接为最多 5 分的附加项。

据此，最优先且改动最小的方向是 **v2.0.0 逐元素来源反查**：父版已经要求 `figure_spec.json` 与 `source_map.json`，新增一次确定性反查即可覆盖“实体、关系、数值与单位能否追溯”和“能否独立复核”，不必替换渲染或导出链路。相邻题目的既有同批试验也显示“逐元素出处台账”曾是该题最高分方向，但那不是本题的分项证据，不能承诺本题增益。

## 三、五个独立实验版本

五个目录均直接复制 v1.0.1 的四个执行资源，再只增加一个 validator 和必要的接口/调用说明；所有版本的 `scripts/diagram.py` 与 v1.0.1 逐字节一致。它们是相互独立的单点实验，不逐级叠加。

| 版本 | 唯一方向 | 针对的可检验缺口 | 评分细则中的对应面 |
|-|-|-|-|
| v2.0.0-来源反查 | 独立重读来源文件、SHA256、定位与引文，并回查 spec/SVG ID | 来源覆盖、哈希漂移、引文不符、漏绘 ID | 正确性、可核验性、创新证据 |
| v2.1.0-结构层级审计 | spec 与真实 SVG 的端点、标记、几何及包含关系对账 | 悬空端点、方向标记错、节点逸出分组、层级断裂 | 关系/方向/层级正确性 |
| v2.2.0-图面碰撞回修 | 确定性近似几何审计并强制修订后重渲染 | 文本越界、标签重叠、连线穿过文字 | 图面规范、质量增益、返工减少 |
| v2.3.0-数据图例对账 | 独立重读原始单元格，逐项核对值—图元—图例—单位 | 数据修改后图未同步、图例错色错名、零值被当缺失 | 数据映射正确性、可复核性、方法改进 |
| v2.4.0-源文件保留编辑 | 按稳定 ID 比较原始/修订 SVG，实际变化必须精确等于声明变化 | 未声明对象被改、原始 ID 丢失、变更台账哈希不符 | 源文件保留、可编辑性、修改可追溯 |

上述均为与评分细则对应的改进假设，只有平台正式出分才能确认是否提分。本地合成测试只验证工具行为，不是官方成绩或科学正确性证明。
